Company switcher preferred users

Your companies first in the company switcher

Set the preferred users of each company: in the company switcher, every user sees first the companies they work on.

Key features

"Preferred users" field on companies, several internal users per company
The companies of the user listed first in the native company switcher
Order changed for each user only: nothing written in the database, no change of access rights
No JavaScript, only depends on Web, works with the Multi-company selection counter module

Setup steps

  1. Install the module: web_company_switcher_preferred_user
  2. In Settings > Companies, add the Preferred users of each company
  3. The user reloads the page: their companies are now listed first in the company switcher

Known limitations

  • Branches (child companies) stay under their parent company, only top-level companies are reordered
  • A change of the preferred users shows in the switcher after a page reload
