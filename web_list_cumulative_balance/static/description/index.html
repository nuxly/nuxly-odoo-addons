Account List Cumulative Balance

Live running balance to speed up manual reconciliation

Adds a "Cumulative Balance" column to the Journal Items list, so accountants can select entries and watch, live, whether they sum to zero — no more reconciling with a calculator on the side.

Key Features

Running total of the Balance column, in the order currently shown on screen
Select any lines, consecutive or not, and the cumulative total recalculates instantly using only the selected lines
Fully live: no button to click, the column updates as you check or uncheck lines
Follows whatever sort, filter or grouping is currently applied to the list
Optional column, placed right after the standard Balance column, toggled from the column selector
Standalone module, only depends on Accounting — no configuration needed

Setup Steps

  1. Install the module: web_list_cumulative_balance
  2. Open Accounting > Accounting > Journal Items
  3. Enable the Cumulative Balance column from the column selector, if not shown by default
  4. Select the lines you want to check, and read the balance directly on the last selected line

Why this Module?

Manual reconciliation (e.g. on cash or clearing accounts) usually means picking entries one by one and adding them up outside of Odoo to check whether they balance to zero — slow, and easy to get wrong on long lists.

This module removes that manual step: pick any lines directly in the Journal Items list, in any order, and the cumulative balance is computed and displayed live, right in the list, next to the standard Balance column.
